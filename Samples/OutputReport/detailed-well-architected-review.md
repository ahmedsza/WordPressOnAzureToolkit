## 4. Reliability

This is a genuinely resilient platform build: three zone-redundant PremiumV3 workers, zone-redundant
MySQL with a healthy standby, 35-day geo-redundant database backups, GZRS media storage with
versioning and point-in-time restore, and a full availability-alerting stack. The one evidenced
failure is that the recovery windows across the tiers do not line up, and the largest residual risk
is that none of it has been restore-tested.

## 5. Security

The security posture is the strongest part of this workload. The origin is genuinely locked to Front
Door with both a service tag and the Front Door identifier header, every data service is private with
no public path, MySQL is Microsoft Entra authentication-only with TLS enforced, and no storage
account accepts shared-key access. Three failures remain: WordPress administration paths are only
partially protected, WordPress-level hardening settings are absent, and Defender for Cloud has no
security contact to notify.
